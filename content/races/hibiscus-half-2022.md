This is the race that made the marathon real.

In December 2021 Michelle watched the Honolulu Marathon and said we should run it the next year for Jay's fiftieth. At that point the longest either of us had run was the Great Aloha Run, 8.2 miles. A marathon wasn't a plan. It was something somebody said at a finish line.

The [rule we keep](/lessons/dont-sign-up-before-the-long-run) is that the race doesn't get paid for until the long run exists. So the first job of 2022 wasn't the marathon. It was a half. If we could get to 13.1, the marathon became something we could picture. If we couldn't, it slid to the next year and that would've been fine.

## The race

Hibiscus is Memorial Day weekend, out of Kapiolani Park, with an early start because by 8 a.m. Honolulu is done being nice to you. The course takes you around Diamond Head, which is a climb that looks small on a map and feels a lot bigger at mile ten in the humidity.

First half marathon for both of us. We're not going to make up how it felt mile by mile, because this was before the camera and before the log, and memory is a liar about pace. We finished. That was the whole goal. Now the long run existed.

## What it set up

We paid for the marathon after this. December 2022, the [fiftieth birthday race](/races/honolulu-marathon-for-fifty). A year later, same race, Michelle ran [2:12](/races/hibiscus-half-2023) with Jay pacing her. Same course, different people.

If you're 45 and up and thinking about a marathon, this is the rung to stand on first. Not because a half is easy. Because it tells you the truth about the next one before you've paid for it.
